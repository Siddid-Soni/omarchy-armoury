# Plan 3 — GPU mode switching

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `armoury gpu set <integrated|hybrid|ultimate>` switches GPU mode by the spec's matrix, refuses anything that could reach the black-screen state, shows pending switches, and offers the first step of the two-step Integrated↔Ultimate path. `armoury gpu plan <mode>` shows what a switch would do without doing it.

**Architecture:** A pure `features::gpu::plan_switch(&GpuState, target) -> Result<Step, String>` encodes the matrix and guards. The daemon executes a `Step`: Hybrid↔Integrated launches Omarchy's own toggle exactly as the Omarchy menu does (`omarchy-launch-floating-terminal-with-presentation omarchy-toggle-hybrid-gpu`, detached with `setsid -f`); Hybrid↔Ultimate calls supergfxd `SetMode` over D-Bus (allowed for the `users`/`wheel` groups, no root). Nothing reboots automatically.

**Tech Stack:** as before.

**Spec:** §4.3 (as amended in brainstorming: Integrated↔Ultimate is manual two-step via Hybrid, no automated chain).

## Global Constraints

- Never produce `gpu_mux_mode=0` with `dgpu_disable=1` (black screen). supergfxd AsusMuxDgpu only from Hybrid with `dgpu_disable=0`; Integrated only with `mux=1`.
- A pending switch (supergfxd `PendingMode` ≠ None) blocks further switches until reboot.
- Writes only in active mode (G-Helper also manages the GPU in observe mode).
- supergfxd calls use `with_retry` (it can wedge).
- No automatic reboot; responses say when a reboot is needed.

**Facts:** supergfxd `SetMode(u) -> u` returns a user action: 0 Logout, 1 Reboot, 2 SwitchToIntegrated, 3 AsusEgpuDisable, 4 Nothing. Mode codes as in Plan 1 (0 Hybrid, 1 Integrated, 5 AsusMuxDgpu). The dGPU users list (Plan 2b) is shown before switching to Integrated.

## Review Focus

1. Pending switch then another request → refused with the pending mode named (`pending_blocks_switch`).
2. Black-screen combinations reachable from any state/target pair → none (`no_step_reaches_black_screen`, exhaustive over mux/dgpu_disable/mode/target).
3. Target not supported by this machine (e.g. no MUX) → refused (`unsupported_target_refused`).
4. supergfxd wedged during SetMode → error within the retry budget, no hang (covered by `with_retry`).
5. Observe mode → refused (`gpu_switch_requires_active`).

### Task 2: Switch planner

**Files:** Create `crates/armouryd/src/features/gpu.rs`; `features/mod.rs`.

**Produces:** `pub fn plan_switch(g: &GpuState, target: GpuMode) -> Result<GpuStep, String>`.

Rules, in order:
1. `g.mode` None → Err "supergfxd is not answering".
2. `g.pending` Some(p) → Err "a switch to {p:?} is pending; reboot first".
3. target not in `g.supported` (or not one of Integrated/Hybrid/AsusMuxDgpu) → Err "{target} is not supported on this machine".
4. target == current → Err "already in {target}".
5. Hybrid→Integrated: require `mux != Some(0)` → `OmarchyToggle{Integrated}`. Integrated→Hybrid → `OmarchyToggle{Hybrid}`.
6. Hybrid→AsusMuxDgpu: require `dgpu_disable != Some(1)` → `Supergfx{AsusMuxDgpu}`. AsusMuxDgpu→Hybrid → `Supergfx{Hybrid}`.
7. Integrated→AsusMuxDgpu → `FirstOfTwo{ first: OmarchyToggle{Hybrid}, then: AsusMuxDgpu }`. AsusMuxDgpu→Integrated → `FirstOfTwo{ first: Supergfx{Hybrid}, then: Integrated }`.
8. Anything else → Err "no path from {current} to {target}".

- [ ] Tests (write first, watch fail):

```rust
fn st(mode: GpuMode, mux: u8, off: u8) -> GpuState {
    GpuState { mode: Some(mode), supported: vec![GpuMode::Integrated, GpuMode::Hybrid, GpuMode::Vfio, GpuMode::AsusMuxDgpu], mux: Some(mux), dgpu_disable: Some(off), ..Default::default() }
}

#[test]
fn matrix() {
    use GpuMode::*;
    assert_eq!(plan_switch(&st(Hybrid, 1, 0), Integrated), Ok(GpuStep::OmarchyToggle { to: Integrated }));
    assert_eq!(plan_switch(&st(Integrated, 1, 1), Hybrid), Ok(GpuStep::OmarchyToggle { to: Hybrid }));
    assert_eq!(plan_switch(&st(Hybrid, 1, 0), AsusMuxDgpu), Ok(GpuStep::Supergfx { to: AsusMuxDgpu }));
    assert_eq!(plan_switch(&st(AsusMuxDgpu, 0, 0), Hybrid), Ok(GpuStep::Supergfx { to: Hybrid }));
    assert_eq!(plan_switch(&st(Integrated, 1, 1), AsusMuxDgpu),
        Ok(GpuStep::FirstOfTwo { first: Box::new(GpuStep::OmarchyToggle { to: Hybrid }), then: AsusMuxDgpu }));
    assert_eq!(plan_switch(&st(AsusMuxDgpu, 0, 0), Integrated),
        Ok(GpuStep::FirstOfTwo { first: Box::new(GpuStep::Supergfx { to: Hybrid }), then: Integrated }));
    assert!(plan_switch(&st(Hybrid, 1, 0), Hybrid).unwrap_err().contains("already"));
}

#[test]
fn pending_blocks_switch() {
    let mut g = st(GpuMode::Hybrid, 1, 0);
    g.pending = Some(GpuMode::AsusMuxDgpu);
    assert!(plan_switch(&g, GpuMode::Integrated).unwrap_err().contains("AsusMuxDgpu"));
}

#[test]
fn unsupported_target_refused() {
    let mut g = st(GpuMode::Hybrid, 1, 0);
    g.supported = vec![GpuMode::Integrated, GpuMode::Hybrid];
    assert!(plan_switch(&g, GpuMode::AsusMuxDgpu).unwrap_err().contains("not supported"));
    assert!(plan_switch(&g, GpuMode::Vfio).is_err());
}

#[test]
fn no_step_reaches_black_screen() {
    use GpuMode::*;
    for mode in [Integrated, Hybrid, AsusMuxDgpu] {
        for mux in [0u8, 1] {
            for off in [0u8, 1] {
                for target in [Integrated, Hybrid, AsusMuxDgpu] {
                    let Ok(step) = plan_switch(&st(mode, mux, off), target) else { continue };
                    let first = match &step { GpuStep::FirstOfTwo { first, .. } => (**first).clone(), s => s.clone() };
                    // the only direct write that sets mux=0 must start from dgpu enabled
                    if first == (GpuStep::Supergfx { to: AsusMuxDgpu }) { assert_eq!(off, 0, "{mode:?} mux={mux} off={off} → {target:?}"); }
                    // Integrated (dgpu_disable=1) must never be entered while mux=0
                    if first == (GpuStep::OmarchyToggle { to: Integrated }) { assert_eq!(mux, 1, "{mode:?} mux={mux} off={off} → {target:?}"); }
                }
            }
        }
    }
}
```
