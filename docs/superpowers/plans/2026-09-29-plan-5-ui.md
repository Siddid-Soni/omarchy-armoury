# Plan 5 — Omarchy UI: bar popup + Armoury window

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** the approved UI (brainstorming): bar widget with popup **B** (mode, GPU, 3×2 quick toggles, status lines, observe/takeover banner, "Open Armoury ›") and window **C** (header strip + dashboard tiles Fans, Lighting, Battery, CPU/GPU, Input, System, each opening a detail page). Omarchy theme colours and components throughout. Keyboard idle dim via Quickshell `IdleMonitor`.

**Architecture:** one Omarchy plugin `asus.armoury` in `plugin/` with kinds `bar-widget` (`Widget.qml`) and `panel` (`Window.qml`), installed by symlinking `~/.config/omarchy/plugins/asus.armoury → <repo>/plugin`. Both instantiate `ArmouryClient.qml`: a Quickshell `Socket` subscribed to armouryd events (live snapshot) plus a request `Socket` with an in-order callback queue (armouryd answers one JSON line per request line). No hardware access from QML. The daemon's ROG-key `open_window` summons `asus.armoury`.

**Constraints**
- Never poll `Status` in a loop while the dGPU might be awake (it forces NVML reads); the CPU/GPU page asks for a detail status only while it is open, at most every 5 s.
- Controls render only for capabilities the snapshot reports (no camera, undervolt only if unlocked, NVIDIA only when awake).
- Observe mode: controls disabled, banner offers "Take over"; active mode offers "Hand back".
- Quick-toggle grid adapted to this machine: Keyboard light (cycle), Touchpad, Lid awake on AC, Overdrive, Boot sound, Music (disabled, "Plan 9") — the spec's Camera (no webcam here) and Fn-lock (deferred) are replaced.

**Verification:** `omarchy plugin validate plugin`, `qmllint`, live load in omarchy-shell, screenshots with `grim` checked visually, clicking through each control against a takeover session, then handback.

## Tasks
1. Backend: `open_window` summons `asus.armoury`; `SetKeepOn { on }` request for idle dim.
2. `plugin/manifest.json`, `ArmouryClient.qml`, `Widget.qml` (bar icon + popup B). Install symlink, enable, place in bar, screenshot.
3. `Window.qml`: overlay card, header strip, tiles with live summaries, page navigation, Esc/scrim close. Screenshot.
4. Pages: Fans (draggable 8-point curves per mode, Apply/Reset), CPU/GPU (limits, boost, EPP, NVIDIA, undervolt when unlocked, GPU status, dGPU users), Lighting (effect, colours, speed/direction, brightness, zones), Battery (info, limit, one-shot), Input (ROG/Fn+F5 bindings, touchpad, keyboard idle), System (sleep, refresh per source, OD, boot sound, lid awake, auto profiles, gamma). Screenshot each.
5. Idle dim: `IdleMonitor` in the widget (timeout from plugin settings, default 60 s) → `kbd_idle`/`kbd_resume`.
6. On-device click-through in a takeover session, handback.
